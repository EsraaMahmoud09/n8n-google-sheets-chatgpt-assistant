# Small ChatGPT by Google Sheet 

An automated n8n workflow that integrates **Google Sheets** with **Anthropic Claude (LLM)** to process and respond to queries seamlessly.

### Business Problem

Manually processing text-based data and handling repetitive requests inside Google Sheets consumes employees' time and creates unnecessary manual work, especially as the volume of data increases.

This can lead to:

* Time wasted on repetitive tasks.
* Slow data processing and response times.
* Inconsistent output quality.
* Difficulty scaling operations as workload grows.

### Solution

An automated n8n workflow connects Google Sheets with an AI model to automatically process incoming data or requests and record the generated results back into the spreadsheet.

### Business Outcome

* Reduce time spent on repetitive manual tasks.
* Speed up data processing and response generation.
* Improve consistency of generated outputs.
* Reduce dependency on manual intervention.
* Handle higher workloads without proportionally increasing manual effort.
